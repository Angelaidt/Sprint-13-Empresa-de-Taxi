# Introdução
🚕 Predição de Demanda: Táxi Corrida Maluca Este projeto tem como objetivo otimizar a disponibilidade de motoristas da empresa Taxi Corrida Maluca em aeroportos, através da predição de demanda de passageiros para a hora subsequente.

# Objetivo do Projeto 🎯
Para atrair mais motoristas durante os períodos de maior movimento, a empresa coletou dados históricos de pedidos. O desafio consiste em construir um modelo de série temporal capaz de prever o volume de chamadas com precisão, permitindo que a frota se organize antecipadamente para os horários de pico.
A métrica REQM no conjunto de teste não deve ser superior a 48.
